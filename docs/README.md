## The interpreter

- **[INTERPRETER-SPEC.md](INTERPRETER-SPEC.md)** — the interpreter's **design decision + contract** (BUILT): an isolated, native-safe runtime evaluator that interprets the rule AST instead of generating/evaluating host code. The shared implementation is proven on JVM/GraalVM-native and Node and qualified in a real browser by packed-package semantics (IF224) plus a ratified 250 ms median first-answer release bar under an adaptive 10→50 fresh-process protocol (IF225). It owns the non-functional contract too: **low first-answer latency**, **high warm performance**, and **low relative footprint** (bounded performance caches explicitly allowed/advised); numerical claims are scenario- and protocol-bound rather than generalized across devices. Separately packaged EUPL-1.2 compatibility adapters may later expose Kernel-shaped TypeScript or JVM interfaces; they are not part of the portable core.
- **[INTERPRETER-ARCHITECTURE.md](INTERPRETER-ARCHITECTURE.md)** — the interpreter's **implementation architecture** (the *how*): Kotlin Multiplatform + the dual JVM/JS targets (the one `expect/actual` decimal shim), the `model ← ast ← parse`, `…← eval` package layering, parsing/AST/data structures, the **generator-ready runtime-semantics layering** (Kleene 3VL, the operator registries), the indexed/cache-heavy performance design and its owner-scoped relative-footprint discipline, the **kernel-as-oracle** correctness approach (the differential + the A–E harness series + clean-room), and special topics.
- **[INTERPRETER-FINDINGS.md](INTERPRETER-FINDINGS.md)** — the interpreter's numbered **design-findings** record (its peer of `API-FINDINGS.md`): the *why* behind how the evaluator mirrors the kernel (the clean-room **+ exact-match** #1 rules, enum-keyed operator dispatch, value-list via the typed `==` path, the `$field$`/formal-error own-text divergences, the `GroupFilled` context seam, the injected clock, ISO-text TIME). A rationale record; the routing rule — kernel-behavior truths to `KERNEL-FINDINGS.md`, interpreter design/treatment here.
- **[INTERPRETER-PERFORMANCE.md](INTERPRETER-PERFORMANCE.md)** — the **method** half of the interpreter's non-functional measurement pair: certification protocols for first-answer p95, warm throughput/scaling, fair kernel-Java comparison, and relative dependency/artifact/runtime footprint; benchmark on **real documents**, never the `RepDoc` shortcut. - **[INTERPRETER-PERFORMANCE-RESULTS.md](INTERPRETER-PERFORMANCE-RESULTS.md)** — the dated evidence half, split out 2026-08-15: one `### Checkpoint` entry per measurement session, newest first, each recording a conclusion rather than a run.
