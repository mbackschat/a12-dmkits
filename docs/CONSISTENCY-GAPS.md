# Portable consistency checker — gaps

> **What this is** — where the kernel-free `:consistency` checker ([CONSISTENCY-API](CONSISTENCY-API.md)) reports a model differently from A12's `checkConsistency`: a class it leaves unnamed, or one it names where A12 names another. Each row gives the input, A12's measured class, the kernel law that measured it, and the plan item that settles it. Ids are `DG<n>`, drawn from the chunks declared once in [DEV-API-GAPS](DEV-API-GAPS.md)'s `dg-id-chunks` line, which serves both ledgers.
>
> **Lifecycle.** A gap lives here only while open. When it ships, its row is DELETED in the same commit: the measured behaviour already lives in its [KERNEL-FINDINGS](KERNEL-FINDINGS.md) entry, and the sweep ledger turns the divergence into an agreement. No shipped list, ever.
>
> **Current state.** Since 2026-09-26 the checker's divergences are discovered by the near-miss sweep, and its committed ledger (`adapter/src/test/resources/checker-near-miss/clusters.tsv`) is their list. The rows below were found by hand before that, so their inputs are kept here until they become sweep seeds. Each row names the missing structure behind it and the stage rebuild in [CONFORMANCE-PLAN](CONFORMANCE-PLAN.md) that settles it; none is patched in the family it names.

## 1. Open

- **DG119 — rule-message parameters are read by separate splitters, not one event-ordered decoder.** A12 refuses each parameter at its first parser or lexer event, in the order [KF501](KERNEL-FINDINGS.md#kf501) measures (that one parser per parameter produces the order is a hypothesis); the checker's group reader and its name-position families (plain, form line, category suffix, semantic index) each read a slice of the text. Measured 2026-10-02 against the kernel on the four `Message*AgreementTest` grids added that day, the checker names a WRONG class on these mechanisms: the multi-up walk's extra step before any non-name token (`MessageGroupWalkAgreementTest` `walk-shelf-two-up-{end,double,sign,bracket}`, `walk-bin-two-up-end`; the code special-cases only `RuleGroup`/`BaseYear`); the turning point compared by its whole dotted name, a false rejection (`turning-dotted-correct`, decoder `F3d`); a non-ASCII name character answered as a lookup instead of the lexer class (`P02`, `X02`); the key's syntax after the category check (`N10`); the group-position key judged on name-position classes (`H01`, `H02`, `H05`, `H06`, `K05`, `K06`, `F5a`, `F5b`, `F5d`, `F5f`); syntax faults ahead of a parent walk's per-name lookup (`F2a`–`F2c`); the nesting class ahead of name lookup (`MessageNamePositionAgreementTest` `nested-unknown-{outer,inner,innermost}`); and the message short-name tier gated on `fieldRefByShortNameAllowed`, a false rejection on `off-read` (`off-*` rows; [KF336](KERNEL-FINDINGS.md#kf336)). Settles when one decoder over a shared token stream emits these events in order and every row of the four grids agrees or is explicitly declined. Patching each family would repeat the error.
- **DG120 — the division check counts compositionally instead of walking.** `OperationAnalysis.divisions` sums divisions through `*` and `/` only and gives a call zero, while A12 checks every operator and power and walks its subtree through value-function operands, cut at the first brace, addition or power ([KF503](KERNEL-FINDINGS.md#kf503)). Measured 2026-10-02 on `DivisionWalkAgreementTest`: the checker names `MVK_INVALID_COMPARE_DEC_PLACES` where A12 names `MVK_TOO_MANY_DIV_FOR_CALC` on `h01`–`h05`, `j02`, `j08`, `j12`, `j13`, `j15`, `j17`, `P02`, `P06`, `P10`, `P13`, `P15` and `p02`, and stays silent on the rule rows `v02`, `v04`, `v05` and `R02`. Settles when one walk serves every operator node of both carriers.
- **DG123 — the target-read class is reported once per computation, not once per offending read.** A12 draws `MVK_ERROR_REFERENCE_TO_CALCULATED_FIELD` for each read of the computed field it judges: `[Total] + [Total]` twice, a self-reading precondition and operation twice, `FieldFilled(Total)` over `[Total] + [Total]` three times ([KF181](KERNEL-FINDINGS.md#kf181), `ComputationGateOrderAgreementTest` `J08`, `D01`, `T12`); `ComputationSelfRead` returns its first match. Measured 2026-10-02 on a String target and on a suppressed number target, where the checker reports the class once. Settles when the walk reports every judged read.
- **DG124 — `FirstFilledValue` takes its scale from its first field.** `OperationAnalysis` types the call as its first listed field, so `FirstFilledValue(Base, Ratio)` into the scale-0 `Total` is silent where A12 draws `MVK_INVALID_COMPARE_DEC_PLACES`; `FirstFilledValue(Ratio, Base)` agrees (`ComputationGateOrderAgreementTest` `W05`, measured 2026-10-02). Settles when the scale comparison sees every listed field.
- **DG125 — a literal operand of `Abs` in a computation goes unjudged.** A12 refuses `Abs(2)` with `MVK_NO_CONST` alone, under `*` and under `+` ([KF167](KERNEL-FINDINGS.md#kf167), `ComputationGateOrderAgreementTest` `P03`, `P04`, measured 2026-10-02); the checker asks that question only of the `Round*` operation forms (`RoundingOperands`). Settles when one wrapper gate covers `Abs` with the rounding forms.
