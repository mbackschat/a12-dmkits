# Portable consistency checker — gaps

> **What this is** — where the kernel-free `:consistency` checker ([CONSISTENCY-API](CONSISTENCY-API.md)) reports a model differently from A12's `checkConsistency`: a class it leaves unnamed, or one it names where A12 names another. Each row gives the input, A12's measured class, the kernel law that measured it, and the plan item that settles it. Ids are `DG<n>`, drawn from the chunks declared once in [DEV-API-GAPS](DEV-API-GAPS.md)'s `dg-id-chunks` line, which serves both ledgers.
>
> **Lifecycle.** A gap lives here only while open. When it ships, its row is DELETED in the same commit: the measured behaviour already lives in its [KERNEL-FINDINGS](KERNEL-FINDINGS.md) entry, and the sweep ledger turns the divergence into an agreement. No shipped list, ever.
>
> **Current state.** Since 2026-09-26 the checker's divergences are discovered by the near-miss sweep, and its committed ledger (`adapter/src/test/resources/checker-near-miss/clusters.tsv`) is their list. A row found by hand names its input, the missing structure behind it and the stage rebuild in [CONFORMANCE-PLAN](CONFORMANCE-PLAN.md) that settles it, and is kept here until it becomes a sweep seed.

## 1. Open

- **DG158 — a field `label` entry whose `text` is `null` (opened 2026-10-27).** A12's reader refuses the source ("Unexpected node type for localized text: NULL"), with or without an `ONLY` filter on the field, so A12 reaches no verdict; the checker reads the model and reports nothing where it should report `CK_MODEL_NOT_BUILDABLE`. Measured beside [KF626](KERNEL-FINDINGS.md#kf626)'s grid on 2026-10-27. Settled by a reader-tier check of every localized-text member the checker does not yet read, the `errorMessage` shape being the one it already reads (`MessageSlotRawShapeLawsTest`).
- **DG159 — a temporal `format` outside the admitted vocabulary (opened 2026-10-27).** A `TimeType` declared `HH:mm` is refused by A12 with the codeless sentence "The date format is invalid.", and the checker reports nothing, because [TEMPORAL-FORMAT-VOCABULARY](TEMPORAL-FORMAT-VOCABULARY.md) is not claimed closed and refusing every format outside it would rest a refusal on the limit of a probe ([KF313](KERNEL-FINDINGS.md#kf313)). Met as a fixture slip while measuring [KF627](KERNEL-FINDINGS.md#kf627). Settled by publishing the derived Refused set into `:consistency` from `:dumpTemporalVocabulary` and refusing its members alone, after measuring whether an `ONLY` filter lifts the sentence.
- **DG160 — basic sentences across several type definitions (opened 2026-10-27).** A12's `BasicConsistencyCheck` walks the type definitions before the elements and tests each definition's id and name in turn (source-read), so two defective definitions order and repeat their sentences in a way no row has measured, on either side. The agreement test compares sets, so it cannot see a difference. Settled by a two-definition, two-defect row compared as an ordered list of A12's sentences against the checker's findings.
- **DG161 — the order of repeated-value sentences (opened 2026-10-27).** Whether A12 states "The enumeration contains the value '…' multiple times." in declaration order, as a checker walking the values would, is not measured. Settled by an Enumeration repeating two values in reverse declaration order, compared as an ordered list.
- **DG162 — an element or type-definition `name` that is not a scalar, or is absent (opened 2026-10-27).** Measured through `BoundModel`: a field's or rule's `name` written as a JSON object or array leaves the model unbuilt where the declaration is kept and draws "The name is empty." alone under an `ONLY` filter that removes it; an absent field `name`, and a type definition's `name` written as an object, leave it unbuilt either way. The checker reports nothing on any of them. A number, `true` or `null` name, and a number as an Enumeration value, agree (`CheckerBasicSentenceAgreementTest`). Settled by reading these members' JSON shapes in the checker's basic-sentence and build tiers, red-first on the five measured rows.

## 2. Out of scope

- **What a document's evaluation fires.** The checker judges a model statically; runtime behaviour is the interpreter's, and its divergences are [INTERPRETER-GAPS](INTERPRETER-GAPS.md)'.
