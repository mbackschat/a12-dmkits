Install

Use the Maven repository with Gradle or Maven. JVM requires Java 21 or newer. Matching predicate dependencies resolve transitively.

repositories {
    maven("https://mbackschat.github.io/a12-consistency-releases/maven/")
    mavenCentral()
}
dependencies {
    implementation("io.github.mbackschat.a12.dm:dm-consistency:@VERSION@")
}

Gradle selects JVM or JS. Java/Maven consumers use io.github.mbackschat.a12.dm:dm-consistency-jvm:@VERSION@. Full installation instructions. This release does not publish to npm or Maven Central.

One toolkit, distinct responsibilities

The checker examines model declarations. The A12 Interpreter evaluates Documents. The Kernel remains the authority for full A12 acceptance.

Read a scoped pass correctly

ALL_CHECKS_PASSED + INCONCLUSIVE means the implemented checks passed. Reports retain complete: false. INVALID means a rejection was established; source diagnostics and coverage gaps must be read separately. Report guide →
